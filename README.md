# LerpUp Testeur

Unity 6 package for the LerpUp website (lerpup.com). It checks your exercise inside Unity and gives you a code to paste on the site.

**Install:** Window > Package Manager > + > Add package from git URL, then paste
`https://github.com/HexoK2/LerpUpTest.git`

**Use:** menu LerpUp > Tester cette salle.

The code is not tamper-proof: see the comments in `Editor/CodeLerpUp.cs`.

---

Paquet Unity 6 du site LerpUp. Il vérifie ton exercice et te donne un code à coller sur le site.

**Installation :** Window > Package Manager > + > Add package from git URL, puis colle
`https://github.com/HexoK2/LerpUpTest.git`

**Utilisation :** menu LerpUp > Tester cette salle.

Ce dépôt est envoyé depuis le dossier `unity/LerpUpTesteur` du projet LerpUp : ne le modifie pas ici.
