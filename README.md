# LerpUp Testeur

Paquet Unity 6 du site LerpUp. Il vérifie ton exercice et te donne un code à coller sur le site.

Installation : Window > Package Manager > + > Add package from git URL, puis
`https://github.com/HexoK2/Devuno.git?path=/unity/LerpUpTesteur`

Utilisation : menu LerpUp > Tester cette salle (voir GUIDE.md, recette 7).

Le code n est pas inviolable : voir les commentaires de `Editor/CodeLerpUp.cs`.
